

# 💰 Expense Tracker (Vue.js)

A modern and responsive Expense Tracker application built with **Vue 3**, **Pinia**, **Vue Router**, and **Chart.js**. The application helps users manage their income and expenses, monitor budgets, and visualize financial data through interactive charts.

## ✨ Features

- 📊 Dashboard with summary cards
- 💵 Add income and expense transactions
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 💾 Local Storage support (data persists after refresh)
- 📈 Reports with interactive charts
- 🎯 Budget Management
- ⚙️ Settings page
- 📱 Responsive user interface

## 📦 Installation

Clone the repository

```bash
git clone 
```

Navigate to the project:

```bash
cd expense-tracker-vue
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
🚀 Deployment

This project is deployed on Vercel.
